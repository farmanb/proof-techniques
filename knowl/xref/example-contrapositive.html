Example 2.1.

Let \(n \in \Z\text{.}\) If \(n^2\) is odd, then \(n\) is odd.
🔗
Solution.
We will utilize a proof by contraposition. Assume \(n\) is even. By definition, there is an integer \(k\) such that \(n = 2k\text{.}\) Then
🔗
\begin{gather*} n^2 = (2k)^2 = 2(2k^2), \end{gather*}
🔗
so \(n^2\) is even, i.e., \(n^2\) is not odd. We have proved the contrapositive, and hence if \(n^2\) is odd, then \(n\) is odd.
