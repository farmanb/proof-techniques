Example 1.1.

If \(n\) is an even integer, then \(n^2\) is even.
🔗
Solution.
Assume \(n\) is even. By definition, there is an integer \(k\) such that \(n = 2k\text{.}\) Then
🔗
\begin{gather*} n^2 = (2k)^2 = 4k^2 = 2(2k^2). \end{gather*}
🔗
Since \(2k^2 \in \Z\text{,}\) it follows that \(n^2\) is even.
